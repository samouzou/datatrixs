# **App Name**: Datatrixs

## Core Features:

- Company & Location Management: Allow administrators to establish holding companies and onboard individual retail locations under their organizational structure.
- Financial Data Integrations: Facilitate connections to QuickBooks accounts and provide robust CSV/Excel upload capabilities for comprehensive financial data ingestion.
- Standardized Financial Data Processing: Automatically ingest, normalize, and categorize financial data from disparate sources into a unified internal schema for consistent analysis.
- Global Performance Dashboard: Present an aggregated view of key performance indicators (KPIs) and financial health across all managed locations for top-level insights.
- AI Financial Analyst Tool: Implement a conversational AI interface where users can query financial data, generate reports, request specific charts, or export tailored spreadsheet data.
- Interactive Data Visualization: Enable users to generate and customize a variety of charts, graphs, and tables for detailed financial data exploration.
- Spreadsheet Data Export: Provide functionality to export any financial analysis, report, or specific dataset directly into spreadsheet formats for further external use.

## Style Guidelines:

- Primary color: '#0173BF' (RGB: 1, 115, 191) a confident and professional blue, to signify reliability and prominence in UI elements.
- Background color: '#434343' (RGB: 67, 67, 67) a deep, neutral charcoal grey for the main interface canvas, promoting focus and readability on a dark theme.
- Accent color: '#01E98F' (RGB: 1, 233, 143) a vibrant and luminous green, used for highlighting critical data points, calls-to-action, and positive performance indicators.
- Secondary color: '#00396D' (RGB: 0, 57, 109) a rich, darker blue for subtle depth, distinctions between UI sections, and active states.
- Overall font: 'Inter' (sans-serif) for all text. Its modern, objective, and highly legible characteristics are ideal for displaying financial figures and complex data reports.
- Utilize a sleek, professional line-iconography style for clarity and quick recognition of various functions and data types across the platform.
- Design a clean, modular, and responsive dashboard layout that prioritizes hierarchical data presentation and intuitive navigation for complex financial oversight.
- Implement subtle, functional animations for data updates, chart transitions, and UI element interactions, ensuring a smooth and sophisticated user experience without unnecessary distraction.
